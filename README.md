# GameBridge – Event Management Module 🎮📅

## 📌 Overview
This repository contains the **Event Management Module** developed as part of the **GameBridge** integrated project.  
The module is designed to manage gaming events, tournaments, and community activities with both administrative control and AI-powered user interaction.

Built during the **Integrated Web Project at ESPRIT**, this module focuses on usability, automation, and engagement.

---

## 🚀 Features

### 🔧 Admin Dashboard
- Create new events
- Update and edit existing events
- Delete events
- Filter events by **period** and **ID**
- Secure and structured event management interface

### 🌐 Front Office
- AI-powered **chatbot** using **OpenAI API**
- Automatic generation of **event posters and thumbnails**
- Interactive and user-friendly event display

---

## 🛠️ Technologies Used
- **HTML** – Structure
- **CSS** – Styling & layout
- **JavaScript** – Client-side interactivity
- **PHP** – Server-side logic
- **OpenAI API** – Chatbot & AI content generation
