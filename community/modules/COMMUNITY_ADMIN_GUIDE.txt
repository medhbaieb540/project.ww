────────────────────

 BECOME ADMIN
═══════════════════════════════════════════════════════════════════

To activate admin powers:

1. Open community.php in text editor
2. Find line 8: $_SESSION['role'] = 'player';
3. Change to: $_SESSION['role'] = 'admin';
4. Save file
5. Refresh browser
6.  Admin buttons appear!


 ADMIN FEATURES
═══════════════════════════════════════════════════════════════════

1️⃣ ADD NEW GAME
───────────────

What you'll see:
• " Add New Game" button at top

How to use:
1. Click "Add New Game"
2. Form slides down
3. Fill in:
   - Game Title (required)
   - Developer Name (required)
   - Category (required - 8 options)
   - Image URL (optional)
   - Feedback Count (optional)
4. Click " Add Game"
5. Game appears instantly!

Example:
Title: Cyber Warriors
Developer: @TechGamer
Category: Action
Image: (leave blank)
Feedback: 0


2️⃣ DELETE GAME
──────────────

What you'll see:
• 🗑️ button on each game card (on hover)

How to use:
1. Hover over any game card
2. Red delete button appears (top-right)
3. Click 🗑️ button
4. Confirm: "Delete this game?"
5. Game fades out and disappears

When to delete:
• Game no longer available
• Duplicate entries
• Testing cleanup
• Inappropriate content


3️⃣ DELETE MESSAGE
─────────────────

What you'll see:
• 🗑️ button on each message (on hover)

How to use:
1. Hover over any message
2. Red delete button appears (top-right)
3. Click 🗑️ button
4. Confirm deletion
5. Message slides out

When to delete:
• Toxic content
• Spam messages
• Harassment
• Inappropriate language
• Rule violations

 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: No admin buttons showing
Solution:
1. Check role = 'admin' (line 8)
2. Must be lowercase
3. Refresh page
4. Clear browser cache

Problem: Can't delete messages
Solution:
1. Verify admin role
2. Check browser console (F12)
3. Ensure delete_message.php exists
4. Check file permissions

Problem: Game won't add
Solution:
1. Fill ALL required fields
2. Check console for errors
3. Verify add_game.php exists
4. Check network tab (F12)

Problem: Delete buttons always visible
Solution:
This is normal on mobile/touch devices
Desktop: Hover to see
Mobile: Always visible
